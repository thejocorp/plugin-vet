# Changelog

## 0.1.0

First release. Scans a local directory or a git URL for:
committed secrets, agent-directed / prompt-injection text, pipe-to-shell installers,
committed binaries, every-tool-call hooks, background services, usage telemetry,
unpinned MCP fetches, skills that ship code, and npm install scripts.
Readable and JSON output, a configurable severity policy, and an exit code for CI.
