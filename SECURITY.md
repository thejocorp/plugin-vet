# Security

plugin-vet is a security tool, so reports about it are welcome and taken seriously.

Please report a vulnerability privately through GitHub: **Security → Report a vulnerability** on
this repository. Do not open a public issue for it. Expect an answer within a few days.

- A bypass (a plugin that does something on the checklist without being reported) counts too:
  open a normal issue for those unless it involves a real, live malicious package.
